# 2D Grid representation

In 2D the grids look like:

```text
                 y
                 ↑
                 │
        y₃       ●──────●──────●──────●──────●
              Δy │      │      │      │      │
        y₂       ●──────●──────●──────●──────●
                 │      │      │      │      │
        y₁       ●──────●──────●──────●──────●
                 │      │      │      │      │
        y₀       ●──────●──────●──────●──────●──→ x
                 x₀     x₁     x₂     x₃     x₄
                           Δx
```
